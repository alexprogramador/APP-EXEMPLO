# API Pessoas - Django REST Framework

## Sobre o projeto

API desenvolvida em Django e Django REST Framework para cadastro,
consulta, atualização e exclusão de pessoas.

## Tecnologias utilizadas

- Python
- Django
- Django REST Framework
- PostgreSQL
- SQLite
- Gunicorn
- WhiteNoise
- Render
- Git
- GitHub

## Funcionalidades

- Cadastro de pessoas
- Consulta de pessoas
- Atualização de pessoas
- Exclusão de pessoas
- API REST
- Interface navegável do Django REST Framework

## Execução local

Ativar o ambiente virtual:

lib\Scripts\activate.bat

Entrar na pasta:

cd api_exemplo\myapp

Executar:

python manage.py runserver

A aplicação ficará disponível em:

http://127.0.0.1:8000/

## Deploy

A aplicação está hospedada no Render.

URL:

https://app-exemplo.onrender.com/
